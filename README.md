# Growth Audit — Salla Partners

**Live:** https://bterzic123.github.io/salla-partners-flow-rebuild/

Salla Partners asks every new partner eight questions, then opens the same dashboard on 0. This audit rebuilds the first session in Salla's own design so each partner type gets its own first step: an affiliate marketer, a service provider and an influencer, side by side.

## The five ideas

| # | Idea | What to measure |
| :-- | :-- | :-- |
| 1 | Open the dashboard on the program they picked | First action in week one, per program |
| 2 | Ask page 2 only of partners who build something | Quiz completion, per partner type |
| 3 | Show the Smart earnings engine right after the quiz | Affiliate links created on day one |
| 4 | End Get started on one first step, not confetti over 0 | Day-one activation, per program |
| 5 | Make the setup moment read their answers back | Share who reach the first step |

## Grounding

Screens, copy and the Smart earnings engine come from the Salla Partners iOS app as recorded on 23 November 2026. 0.4% of store sales, the SAR 20,000 threshold, the 5–30% merchant discount, and Salla Plus (99) and Salla Pro (299) a month are shown on the app's Salla Plans screen. 1,000+ verified partners and 59,700+ active online stores come from partners.salla.com. The influencer profile settings come from the App Store listing.

There are no impact percentages here. Adapty's ranges are measured on subscription purchases, and Salla Partners has no purchase, so each idea names what to measure instead.
